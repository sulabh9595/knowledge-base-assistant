Framework Primer

LangChain

An open-source framework for building applications powered by language models — by linking prompts, models, memory, tools, and data into a single working chain.

01 — The Idea

Why "chain"?

An LLM on its own just predicts text. LangChain gives it a body: a way to pull in outside data, remember past turns, call tools, and hand off decisions to other steps.

LangChain is a Python/JS framework that standardizes how you connect an LLM to everything around it — prompts, documents, APIs, databases, and other models — so you can compose them into a chain of steps instead of writing glue code from scratch each time.

think: LLM = engine · LangChain = the drivetrain, wiring, and dashboard around it
02 — Core Components

Six links in the chain

Every LangChain app is assembled from some combination of these building blocks.

01

Models

Wrappers around LLMs (GPT, Claude, Gemini, Ollama-hosted local models) behind one consistent interface.

02

Prompts

Templates that structure instructions, few-shot examples, and variables fed into the model.

03

Chains

Sequences of calls — model, tool, parser — composed into a single reusable pipeline (LCEL).

04

Memory

Carries conversation history or state across turns, so the app doesn't forget context.

05

Retrievers

Fetch relevant chunks from vector stores or documents — the backbone of RAG.

06

Agents & Tools

Let the model decide which tool to call next — search, code, an API — rather than following a fixed path.

04 — Getting Hands-On

Basic commands & methods

The install command plus the handful of methods you'll reach for in almost every LangChain script.

Install

Setup
# core + a model provider + a vector store
pip install langchain langchain-openai langchain-community faiss-cpu

Initialize a model

Models
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)
response = llm.invoke("Summarize LangChain in one line")
print(response.content)
.invoke() runs once and returns the full result — every runnable in LangChain (models, chains, retrievers) shares this same method.

Prompt template

Prompts
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate.from_template(
    "Explain {topic} to a {audience}."
)

Build a chain (LCEL)

Chains
from langchain_core.output_parsers import StrOutputParser

chain = prompt | llm | StrOutputParser()
result = chain.invoke({"topic": "RAG", "audience": "QA engineer"})
The | pipe operator is LCEL (LangChain Expression Language) — it links runnables into a chain, left to right.

Retriever / RAG lookup

Retrievers
from langchain_community.vectorstores import FAISS
from langchain_openai import OpenAIEmbeddings

store = FAISS.from_documents(docs, OpenAIEmbeddings())
retriever = store.as_retriever(search_kwargs={"k": 4})
matches = retriever.invoke("self-healing locators")

Add memory

Memory
from langchain_core.chat_history import InMemoryChatMessageHistory
from langchain_core.runnables.history import RunnableWithMessageHistory

chat_with_memory = RunnableWithMessageHistory(
    chain, lambda session_id: InMemoryChatMessageHistory()
)

Agent with tools

Agents
from langchain.agents import create_tool_calling_agent, AgentExecutor

agent = create_tool_calling_agent(llm, tools, prompt)
executor = AgentExecutor(agent=agent, tools=tools)
executor.invoke({"input": "Run the failed test and diagnose it"})
Common methods across all of these: .invoke() · .stream() (token-by-token) · .batch() (many inputs at once).
05 — The Ecosystem

Beyond the core library

LangChain has grown into a family of tools for different stages of building and running an LLM app.

Orchestration

LangGraph

Graph-based framework for multi-agent, stateful workflows — branching logic, loops, and human-in-the-loop steps that a linear chain can't express.

Observability

LangSmith

Traces, debugs, and evaluates chains and agents in production — see exactly what prompt and context produced each output.

Deployment

LangServe

Turns a LangChain pipeline into a REST API in a few lines, ready to call from any client app.

06 — Why It Matters

One interface, many moving parts

Instead of hand-rolling integrations for every model, vector store, and API, LangChain gives teams a common set of abstractions — which is exactly why it shows up so often in agentic-AI and test-automation tooling today, from self-healing locators to multi-agent QA pipelines.
